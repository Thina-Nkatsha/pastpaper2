MOBILE DEVICE SALES JAVA PROGRAM

Open MobileDeviceSales.java in IntelliJ IDEA and run the main method.

The program uses a two-dimensional array to store January, February and March
2018 sales for IPhone 7, Samsung S8 and Huawei Mate 10.

It displays:
- The monthly mobile device sales report
- The total sales for each device
- The monthly totals
